8.0הפרדת משתנים בקורדינטות גליליות

הגדרת קורדינטות גליליות מתוארת באיור 59. בקורדינטות אלו, משוואת לפלאס היא

\[\nabla^2\Phi = \frac1r\frac{\partial}{\partial r}\left(r\frac{\partial\Phi}{\partial r}\right) + \frac{1}{r^2}\frac{\partial^2\Phi}{\partial\varphi^2} + \frac{\partial^2\Phi}{\partial z^2} = 0\]
(8.1)

באופן דומה לתהליך שבו השתמשנו במקרה הקרטזי, ניקח פתרון בהפרדת משתנים מהצורה

\[\Phi = R(r)\,F(\varphi)\,Z(z)\]
(8.2)

נציב חזרה במשוואת לפלאס

\[\nabla^2\Phi = F\cdot Z\cdot\frac1r\frac{\partial}{\partial r}(rR') + \frac{1}{r^2}F''RZ + FRZ'' = 0\]
(8.3)

כעת, נחלק את המשוואה שהתקבלה ב־\(FRZ\) ונקבל

\[\frac{1}{Rr}\cdot\frac{\partial}{\partial r}(rR') + \frac{1}{r^2}\frac{F''}{F} = -\frac{Z''}{Z}\]
(8.4)

במקרה זה יש לבצע את ההפרדה בשני שלבים. בשלב ראשון, נשים לב כי אגף ימין של משוואה זו תלוי במשתנה \(z\) בלבד, ואגף שמאל במשתנים \(r, \varphi\), ולכן כל אחד מהם חייב להיות שווה לקבוע. מכאן, משוואת ההפרדה עבור \(Z(z)\) תהיה

\[\frac{Z''}{Z} = -k_z^2\]
(8.5)

וזו משוואה מוכרת, שקיבלנו גם בבעיה הקרטזית (זה לא מפתיע כלל, מכיוון שקורדינטה \(z\) היא אותה קורדינטה גם בקרטזיות וגם בגליליות). עבור אגף שמאל של משוואת ההפרדה המלאה נקבל

\[\frac{1}{Rr}\cdot\frac{\partial}{\partial r}(rR') + \frac{1}{r^2}\frac{F''}{F} = k_z^2\]
(8.6)

נכפול ב־\(r^2\):

\[\underbrace{\frac rR\cdot\frac{\partial}{\partial r}(rR') - k_z^2r^2}_{\text{depends only on }r} + \underbrace{\frac{F''}{F}}_{\text{depends only on }\varphi} = 0\]
(8.7)

מכאן, ניתן לרשום שתי משוואות הפרדה נוספות עבור \(R, F\). עבור \(F\):

\[\frac{F''}{F}\equiv-\nu^2\]
(8.8)

ועבור \(R\):

\[\frac1r\frac{\partial}{\partial r}(rR') - \left(\frac{\nu^2}{r^2} + k_z^2\right)R = 0\]
(8.9)

ובסך הכל יש שני קבועי הפרדה בלתי תלויים: \(\nu, k_z\).

8.1סיווג הפתרונות

אצלנו בקורס אנחנו נתמקד בפתרונות דו־ממדיים, כלומר שאינם תלויים בקורדינטה \(z\), ולכן נניח בשלב זה ש־\(k_z = 0\).

הפתרון הטריוויאלי

פתרון זה מקיים \(\nu = 0,\ k_z = 0\). מתוך משוואות ההפרדה נקבל

\[\begin{cases}F'' = 0 \;\Rightarrow\; F = A\varphi + B\\ Z'' = 0 \;\Rightarrow\; Z = Cz + D\end{cases}\]
(8.10)
\[\Rightarrow\; \frac1r\frac{\partial}{\partial r}(rR') = 0 \;\Rightarrow\; rR' = E \;\Rightarrow\; R' = \frac Er \;\Rightarrow\; R = E\ln(r) + F\]
(8.11)

הפתרון הכללי

פתרון זה מקיים \(\nu\neq0,\ k_z = 0\):

\[\frac{F''}{F} = -\nu^2 \;\Rightarrow\; F'' + \nu^2F = 0\]
(8.12)

ניתן לסווג בנוסף, על פי הערך של \(\nu^2\).

  • אם \(\nu^2\gt0\): \(F(\varphi) = A\cos(\nu\varphi) + B\sin(\nu\varphi)\). הצבה חזרה במשוואה עבור \(R\): \(r^2R'' + rR' - \nu^2R = 0 \Rightarrow R = Er^\nu + Fr^{-\nu}\). משפחת פתרונות זו מתאימה למקרה שבו אנחנו רוצים לפרוס תנאי שפה מסוים לאורך קורדינטה \(\varphi\), כמו שנראה בדוגמאות.
  • אם \(\nu^2\lt0\): נגדיר \(\nu\equiv i\tilde\nu\), ואז \(F'' - \tilde\nu^2F = 0 \Rightarrow F = A\sinh(\tilde\nu\varphi) + B\cosh(\tilde\nu\varphi)\). נציב במשוואה ל־\(R\): \(R = \tilde E\cos(\tilde\nu\ln(r)) + \tilde F\sin(\tilde\nu\ln(r))\). משפחת פתרונות זו מתאימה למקרה שבו אנחנו רוצים לפרוס תנאי שפה מסוים לאורך קורדינטה \(r\). שימו לב שלא קיבלנו פריסה באמצעות פתרונות \(\sin, \cos\) בצורה ”רגילה”, וזאת מכיוון שלאורך קורדינטה \(r\) האורתוגונליות של הפתרונות מוגדרת ביחס למכפלה פנימית שונה מהמקרה הקרטזי הרגיל (פונקציית המשקל תהיה \(r\)).

8.2דוגמא 1

הגאומטריה מתוארת באיור 60. שני משטחים אינסופיים בכיוון \(z\) יוצרים זווית \(\alpha\) ביניהם, ומחוברים לפוטנציאלים כמוראה בתרשים. יש לחשב את \(\Phi\) בין הלוחות הללו. מאחר ובין הלוחות אין מטען, הפוטנציאל החשמלי מקיים את משוואת לפלאס. תנאי שפה עבור הפוטנציאל בין הלוחות:

\[\begin{cases}\Phi(\varphi=0) = 0\\ \Phi(\varphi=\alpha) = V_0\end{cases}\]
(8.13)

הבעיה מתאימה לפתרון טריוויאלי. הרמז לכך נמצא בעובדה שתנאי השפה לא תלויים כלל בקורדינטה \(r\).

\[\Phi = (A\varphi + B)\cdot\big(C + \underbrace{D}_{=0}\ln(r)\big)\cdot\big(\underbrace{E}_{=0}z + F\big) = A\varphi + B\]
(8.14)

נציב תנאי שפה:

\[\begin{cases}\Phi(\varphi=0) = B = 0\\ \Phi(\varphi=\alpha) = A\cdot\alpha = V_0 \;\Rightarrow\; A = \dfrac{V_0}{\alpha}\end{cases}\]
(8.15)

לכן:

\[\Phi = \frac{V_0}{\alpha}\cdot\varphi,\qquad \vec E = -\nabla\Phi = -\frac{V_0}{\alpha r}\,\hat\varphi\]
(8.16)

תרשים של הפוטנציאל (צבעים) ושל השדות ניתן לראות באיור 61.

8.3דוגמא 2

נתון תיל אינסופי טעון בצפיפות אחידה, כמוראה באיור 62. נבחר גם כאן בפתרון הטריוויאלי, מאחר ויש סימטריה מלאה של הבעיה לתזוזה בכיוון \(z\) וגם סימטריה מלאה ב־\(\varphi\)

\[\Phi = \big(\underbrace{A}_{=0}\varphi + B\big)\cdot\big(\underbrace{C}_{=0}z + D\big)\cdot\big(E + F\ln(r)\big) = E + F\ln(r)\]
(8.17)

נבחר ייחוס לפוטנציאל ב־\(r = R_0\):

\[\Phi = C_1\ln\left(\frac{r}{R_0}\right)\]
(8.18)

את הקבוע החסר נוכל לקבל מחוק גאוס האינטגרלי:

\[\vec E = -\nabla\Phi = -\frac{C_1}{r}\,\hat r \underset{\text{Gauss's theorem}}{=} \frac{\lambda}{2\pi\epsilon_0}\frac1r\,\hat r \;\Rightarrow\; C_1 = -\frac{\lambda}{2\pi\epsilon_0}\]
(8.19)

8.4דוגמא 3

גליל אינסופי בכיוון \(z\), שרדיוסו \(a\), עשוי ממוליך אידאלי (PEC). בסביבת הגליל מופעל שדה חיצוני \(\vec E_{external} = E_0\hat x\), כמוראה באיור 63. יש לחשב את הפוטנציאל החשמלי והשדה בכל המרחב. מחוץ לגליל הפוטנציאל מקיים את משוואת לפלאס, \(\nabla^2\Phi = 0\). תנאי השפה שעל הפתרון לקיים עבור השדות

\[\begin{cases}\vec E(r\gg a) = E_0\hat x\\ \Phi(r=a) = C\end{cases}\]
(8.20)

ולכן על הפוטנציאל לקיים

\[\Rightarrow\begin{cases}(1)\quad \Phi(r\gg a) = -E_0x = -E_0r\cos\varphi\\ (2)\quad \Phi(r=a) = 0\end{cases}\]
(8.21)

הפתרון הכללי

\[\Phi = \left(Ar^\nu + Br^{-\nu}\right)\cdot\left(C\sin(\nu\varphi) + D\cos(\nu\varphi)\right)\]
(8.22)

מאחר ואנו פותרים בכל התחום הזוויות \(\varphi\in[0,2\pi]\), חייב להתקיים \(\nu = n\in\mathbb N\). מתנאי שפה (1) נבחר \(\nu = n = 1\) ונקבל

\[\Phi = \left(Ar + \frac Br\right)\cdot\left(C\sin\varphi + D\cos\varphi\right)\]
(8.23)

מתנאי שפה (2)

\[\Phi(r=a) = \left(Aa + \frac Ba\right)\cdot\left(C\sin\varphi + D\cos\varphi\right) = 0 \;\Rightarrow\; Aa + \frac Ba = 0 \;\Rightarrow\; B = -Aa^2\]
(8.24)

ומ־(1):

\[\Phi(r\gg a)\approx Ar\cdot\left(C\sin\varphi + D\cos\varphi\right) = -E_0r\cos\varphi \;\Rightarrow\; C = 0,\quad A\cdot D = -E_0 \;\Rightarrow\; B\cdot D = -a^2\cdot A\cdot D = E_0a^2\]
(8.25)

את התוצאה ניתן להציג באופן הבא

\[\Phi = \left(-E_0r + \frac{E_0a^2}{r}\right)\cos\varphi = \underbrace{-E_0r\cos\varphi}_{\text{External potential}} + \underbrace{\frac{E_0a^2}{r}\cos\varphi}_{\text{Reaction}}\]
(8.26)

ניתן לראות שהתוצאה מורכבת למעשה משתי תרומות. החלק הראשון הוא הפוטנציאל החיצוני, הפוטנציאל ש”עורר” את הבעיה. החלק השני הוא פוטנציאל התגובה: פוטנציאל זה נוצר בעקבות תגובת המטענים בגליל לשדה החיצוני. השדה בבעיה יהיה

\[\vec E = -\nabla\Phi = E_0\hat x + \frac{E_0a^2}{r^2}\left(\cos\varphi\,\hat r + \sin\varphi\,\hat\varphi\right)\]
(8.27)

מה יהיה פילוג המטענים על שפת הגליל?

\[\eta = \hat r\cdot\left(\epsilon_0\vec E - \epsilon_0\vec E_{inside}\right)\Big|_{r=a} = \dots = 2\epsilon_0E_0\cos\varphi\]
(8.28)

8.4.1דוגמא 4

נתונה גזרה גלילית, בעלת זווית פנימית \(\alpha\). רדיוס הגזרה \(a\). המשטחים \(\varphi = 0,\ \varphi = \alpha\) עשויים מוליך אידאלי ומוארקים. המשטח \(r = a\) מחובר לפוטנציאל חיצוני \(V(\varphi)\), כמוראה באיור 66. המבנה אינסופי בכיוון \(\hat z\). בתוך הגזרה הפוטנציאל מקיים \(\nabla^2\Phi = 0\), מאחר ומדובר בבעיה סטטית ואין מטענים חופשיים. תנאי השפה

\[\begin{cases}\Phi(\varphi=0) = 0\\ \Phi(\varphi=\alpha) = 0\\ \Phi(r=a) = V(\varphi),\quad \varphi\in[0,\alpha]\end{cases}\]
(8.29)

הפתרון הטריוויאלי לא יכול לקיים את תנאי השפה, לכן נבחר בפתרון הכללי

\[\Phi = \left(Ar^\nu + Br^{-\nu}\right)\left(C\sin(\nu\varphi) + D\cos(\nu\varphi)\right)\]
(8.30)

נציב תנאי שפה:

\[\Phi(\varphi=0) = \left(Ar^\nu + Br^{-\nu}\right)\cdot D = 0 \;\Rightarrow\; D = 0\]
(8.31)

על מנת לפשט את הרישום נגדיר \(A\cdot C\equiv\tilde A,\ B\cdot C\equiv\tilde B\), ונקבל

\[\Phi = \left(\tilde Ar^\nu + \tilde Br^{-\nu}\right)\sin(\nu\varphi)\]
(8.32)

נציב \(\varphi = \alpha\)

\[\Phi(\varphi=\alpha) = \left(\tilde Ar^\nu + \tilde Br^{-\nu}\right)\sin(\nu\alpha) = 0 \;\Rightarrow\; \nu\alpha = \pi n \;\Rightarrow\; \nu = \frac{\pi n}{\alpha},\quad n\in\mathbb N\]
(8.33)

ולכן ניתן להביע את הפתרון על ידי

\[\Phi = \sum_{n=1}^{\infty}\left(\tilde A_nr^{\frac{\pi n}{\alpha}} + \tilde B_nr^{-\frac{\pi n}{\alpha}}\right)\sin\left(\frac{\pi n}{\alpha}\varphi\right)\]
(8.34)

מתוך עיקרון המינימום / מקסימום חייב להתקיים \(\tilde B_n = 0\), על מנת למנוע התבדרות של הפוטנציאל בראשית.

\[\Phi = \sum_{n=1}^{\infty}\tilde A_nr^{\frac{\pi n}{\alpha}}\sin\left(\frac{\pi n}{\alpha}\varphi\right)\]
(8.35)

מכאן מפתחים את המקדמים לפי תנאי השפה הנתון ב־\(r = a\), \(\Phi(r=a) = V(\varphi)\), ומקבלים ביטוי ל־\(\tilde A_n\), באופן זהה לצורה בה עשינו את הפיתוח במקרה הקרטזי. מה השדה?

\[\vec E = -\nabla\Phi = -\hat r\sum_{n=1}^{\infty}\tilde A_n\frac{\pi n}{\alpha}r^{\frac{\pi n}{\alpha}-1}\sin\left(\frac{\pi n}{\alpha}\varphi\right) - \hat\varphi\sum_{n=1}^{\infty}\tilde A_n\frac{\pi n}{\alpha}r^{\frac{\pi n}{\alpha}-1}\cos\left(\frac{\pi n}{\alpha}\varphi\right)\]
(8.36)

נשים לב, כי באיבר הראשון \(n = 1\) החזקה של \(r\) יכולה להיות שלילית כאשר \(\alpha\gt\pi\). כלומר, כאשר מבנה התחום הוא כזה שיש ”שפיץ” בראשית, אנחנו מקבלים שהשדה יתבדר בראשית, כפי שאנחנו מצפים. באיור 67 ניתן לראות תרשים של הפוטנציאל והשדה עבור \(\alpha\lt\pi\). ניתן לראות כי השדה רגולרי בראשית. לעומת זאת, באיור 68 רואים את התבדרות השדה בראשית.

8.5שיקולי אנרגיה בנוכחות סינגולריות של השדה החשמלי

במהלך פתרון הדוגמאות בקורדינטות גליליות, ראינו שני סוגים של התנהגות סינגולרית. מקרה ראשון היה בסעיף 8.2, בו ראינו פתרון שהוביל לשדה החשמלי

\[\vec E = -\frac{V_0}{\alpha r}\,\hat\varphi\]
(8.37)

האנרגיה החשמלית ליחידת עומק של המבנה במקרה זה תהיה

\[U_E = \int\frac{\epsilon_0}{2}|E|^2\,dV = \int_{r=0}^{a}\int_{\varphi=0}^{\alpha}\frac{\epsilon_0}{2}\left(\frac{V_0}{\alpha}\right)^2\frac{1}{r^2}\,r\,dr\,d\varphi\;\to\;\infty\]
(8.38)

וקיבלנו שהאנרגיה האגורה סביב הסינגולריות מתבדרת. לעומת זאת, במקרה של הדוגמא הקודמת נקבל, על ידי שימוש במשוואה 8.36 (עם \(\tilde A_n = V_n/a^{\pi n/\alpha}\))

\[U_E = \int\frac{\epsilon_0}{2}|E|^2\,dV = \frac{\epsilon_0}{2}\int_{r=0}^{a}\int_{\varphi=0}^{\alpha}r\,dr\,d\varphi\sum_{n=1}^{\infty}\sum_{m=1}^{\infty}\frac{nm\pi^2V_mV_n}{\alpha^2a^2}\left(\frac ra\right)^{\frac\pi\alpha(n+m)-2}\times\left[\sin\left(\frac{n\pi}{\alpha}\varphi\right)\sin\left(\frac{m\pi}{\alpha}\varphi\right) + \cos\left(\frac{n\pi}{\alpha}\varphi\right)\cos\left(\frac{m\pi}{\alpha}\varphi\right)\right]\]
(8.39)

את האינטגרל על \(\varphi\) ניתן לבצע מיד. מתקיים \(\sin\left(\frac{n\pi}{\alpha}\varphi\right)\sin\left(\frac{m\pi}{\alpha}\varphi\right) + \cos\left(\frac{n\pi}{\alpha}\varphi\right)\cos\left(\frac{m\pi}{\alpha}\varphi\right) = \cos\left(\frac{(n-m)\pi}{\alpha}\varphi\right)\), ולכן האינטגרל על \(\varphi\in[0,\alpha]\) שווה ל־\(\alpha\,\delta_{nm}\), ונשארים רק האיברים \(n = m\):

\[U_E = \frac{\epsilon_0}{2}\sum_{n=1}^{\infty}\frac{n^2\pi^2V_n^2}{\alpha a^2}\int_0^a\left(\frac ra\right)^{\frac{2\pi n}{\alpha}-2}r\,dr = \frac{\epsilon_0}{2}\sum_{n=1}^{\infty}\frac{n^2\pi^2V_n^2}{\alpha a^2}\cdot\frac{\alpha a^2}{2\pi n} = \frac{\pi\epsilon_0}{4}\sum_{n=1}^{\infty}n\,V_n^2\]
(8.40)
המסקנה

האינטגרל הרדיאלי מתכנס עבור כל זווית \(\alpha\): סביב הראשית האינטגרנד מתנהג כמו \(r^{\frac{2\pi n}{\alpha}-1}\), והחזקה תמיד גדולה מ־\(-1\). כלומר, גם כאשר \(\alpha\gt\pi\) והשדה בראשית מתבדר כמו \(r^{\frac\pi\alpha-1}\), האנרגיה האגורה סביב ה”שפיץ” סופית: הסינגולריות של השדה היא סינגולריות אינטגרבילית.

זאת בניגוד למשוואה 8.38. שם שני המשטחים, הנמצאים בפוטנציאלים שונים, נפגשים בראשית, השדה מתנהג כמו \(1/r\) בכל הכיוונים, והאנרגיה מתבדרת לוגריתמית. מכאן שהתבדרות של האנרגיה לא נובעת מהפינה החדה עצמה, אלא מאי־רציפות בתנאי השפה: מגע בין משטחים הנמצאים בפוטנציאלים שונים.

מתי התוצאה סופית? כל איבר בטור סופי, כי התרומה של סביבת הראשית תמיד סופית. לכן השאלה אם האנרגיה הכוללת סופית תלויה רק באופן שבו הפוטנציאל \(V(\varphi)\) על הקשת \(r = a\) מתנהג. אם \(V(\varphi)\) משתנה ברציפות ומתאפס בקצוות \(\varphi = 0\) ו־\(\varphi = \alpha\), כך שהוא ”מתחבר” בצורה חלקה לדפנות המוארקות, המקדמים \(V_n\) קטנים מהר מספיק והטור מתכנס. אם לעומת זאת יש בפוטנציאל קפיצה, לדוגמא \(V = V_0\) קבוע שקופץ ל־0 בקצוות, המקדמים קטנים רק כמו \(1/n\), והטור \(\sum nV_n^2\) מתבדר. מאחר וצפיפות האנרגיה חיובית תמיד, טור מתבדר כאן אומר שהאנרגיה באמת אינסופית. הסיבה היא אותה סיבה כמו במשוואה 8.38: נקודת מגע בין משטחים בפוטנציאלים שונים. ההבדל היחיד הוא שכאן נקודות המגע הן הפינות החיצוניות שב־\(r = a\), ולא הראשית.
