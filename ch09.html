9.1פתרון בהפרדת משתנים: קורדינטות כדוריות

היכולת לפתור את משוואת לפלאס בקורדינטות כדוריות היא חשובה במיוחד: אלו למעשה הקורדינטות היחידות, מבין אלו שאנחנו לומדים, שבעזרתן אפשרי למדל בצורה מסודרת מבנים סופיים במרחב. באיור 69 ניתן לראות את ההגדרה של הקורדינטות \(r, \theta, \varphi\). בקורדינטות כדוריות, משוואת לפלאס היא

\[\nabla^2\Phi = \frac{1}{r^2}\frac{\partial}{\partial r}\left(r^2\frac{\partial\Phi}{\partial r}\right) + \frac{1}{r^2\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial\Phi}{\partial\theta}\right) + \frac{1}{r^2\sin^2\theta}\frac{\partial^2\Phi}{\partial\varphi^2} = 0\]
(9.1)

פתרון בהפרדת משתנים יהיה

\[\Phi = R(r)\,T(\theta)\,\Psi(\varphi)\]
(9.2)

נציב במשוואת לפלאס ונקבל

\[\nabla^2\Phi = \frac{1}{r^2}\frac{\partial}{\partial r}\left(r^2R'T\Psi\right) + \frac{1}{r^2\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\,RT'\Psi\right) + \frac{1}{r^2\sin^2\theta}\Psi''RT = 0\]
(9.3)

נכפול ב־\(\frac{r^2\sin^2\theta}{RT\Psi}\) ונקבל

\[\underbrace{\frac{\sin^2\theta}{R}\frac{\partial}{\partial r}\left(R'r^2\right) + \frac{\sin\theta}{T}\frac{\partial}{\partial\theta}\left(T'\sin\theta\right)}_{\text{function of }r,\theta\text{ only}} + \underbrace{\frac{\Psi''}{\Psi}}_{\text{function of }\varphi\text{ only}\ \equiv-\mu^2} = 0\]
(9.4)

גם כאן, בדומה למה שעשינו בקורדינטות גליליות, נבצע את ההפרדה בשני שלבים. ראשית, נפתור את המשוואה עבור \(\Psi\)

\[\frac{\Psi''}{\Psi} = -\mu^2 \;\Rightarrow\; \Psi'' + \mu^2\Psi = 0\]
(9.5)

אצלנו \(\mu^2\gt0\), ולכן:

\[\Psi = A\sin(\mu\varphi) + B\cos(\mu\varphi)\]
(9.6)

נציב חזרה את הקבוע \(\mu^2\) (ונחלק ב־\(\sin^2\theta\)), ונקבל

\[\underbrace{\frac1R\frac{\partial}{\partial r}\left(R'r^2\right)}_{\text{depends only on }r} + \underbrace{\frac{1}{T\sin\theta}\frac{\partial}{\partial\theta}\left(T'\sin\theta\right) - \frac{\mu^2}{\sin^2\theta}}_{\text{depends only on }\theta} = 0\]
(9.7)

כלומר נקבל

\[\begin{cases}\dfrac1R\dfrac{\partial}{\partial r}\left(R'r^2\right) = l(l+1)\\[2ex] \dfrac{1}{T\sin\theta}\dfrac{\partial}{\partial\theta}\left(T'\sin\theta\right) - \dfrac{\mu^2}{\sin^2\theta} + l(l+1) = 0\end{cases}\]
(9.8)

עבור \(r\) נקבל את משוואת אוילר (בה נתקלנו גם בהפרדת משתנים בקורדינטות גליליות)

\[R''r^2 + R'\cdot2r - l(l+1)R = 0 \;\Rightarrow\; R(r) = Cr^l + Dr^{-l-1}\]
(9.9)

עבור \(\theta\) נשתמש בהצבה \(u = \cos\theta\) ונקבל את משוואת לז׳נדר, שפתרונותיה הן ה־associated Legendre functions \(P, Q\)

\[\frac{\partial}{\partial u}\left((1-u^2)\frac{\partial T}{\partial u}\right) + \left(l(l+1) - \frac{\mu^2}{1-u^2}\right)T = 0 \;\Rightarrow\; T(\theta) = AP_l^\mu(\cos\theta) + BQ_l^\mu(\cos\theta)\]
(9.10)

נסכם את משוואות ההפרדה שקיבלנו:

\[\begin{cases}\dfrac{\Psi''}{\Psi} = -\mu^2\\[2ex] \dfrac{\partial}{\partial r}\left(r^2R'\right) - l(l+1)R = 0\\[2ex] \dfrac{\partial}{\partial u}\left[(1-u^2)\dfrac{\partial T}{\partial u}\right] + \left[l(l+1) - \dfrac{\mu^2}{1-u^2}\right]T = 0,\quad u = \cos\theta\end{cases}\]
(9.11)

9.1.1פתרון טריוויאלי

כאשר \(\mu = l = 0\) נקבל

\[\begin{cases}\Psi'' = 0 \;\Rightarrow\; \Psi = A\varphi + B\\[1ex] \dfrac1R\dfrac{\partial}{\partial r}\left(r^2R'\right) = 0 \;\Rightarrow\; R' = \dfrac{\tilde C}{r^2} \;\Rightarrow\; R = \dfrac Cr + D\\[2ex] \dfrac{\partial}{\partial\theta}\left(T'\sin\theta\right) = 0 \;\Rightarrow\; T' = \dfrac{\tilde E}{\sin\theta} \;\Rightarrow\; T = E\cdot\ln\left(\tan(\theta/2)\right) + F\end{cases}\]
(9.12)

9.1.2פתרון כללי

כאשר מתקיים \(\mu\neq0,\ \mu^2\gt0\), נראה כי כבר בשלב הפיתוח רשמנו את הפתרון הכללי:

\[\begin{cases}\Psi = A\sin(\mu\varphi) + B\cos(\mu\varphi)\\ R(r) = Cr^l + Dr^{-l-1}\\ T(\theta) = AP_l^\mu(\cos\theta) + BQ_l^\mu(\cos\theta)\end{cases}\]
(9.13)
הערות
  • אם פותרים בכל התחום \(\varphi\in[0,2\pi]\), אז \(\mu\in\mathbb Z\), ולכן נהוג לרשום \(\mu = m\), באופן דומה לקורדינטות גליליות.
  • אם פותרים בכל התחום \(\theta\in[0,\pi]\), אז \(l\) שלם, וגם כל המקדמים של \(Q\) חייבים להתאפס, מכיוון שפונקציות אלו סינגולריות על ציר \(z\) (מכילות את אותה סינגולריות שיש בפתרון הטריוויאלי, \(\ln[\tan(\theta/2)]\)). ולכן, נשארים עם הפתרון \(T = P_l^m(\cos\theta)\).
  • בבעיות המקיימות סימטריה מלאה ב־\(\varphi\), ניתן לייצג את הפתרונות באמצעות פונקציות לז׳נדר עם \(m = 0\) בלבד.

בין פונקציות לז׳נדר (associated Legendre functions) יש קשר רקורסיבי

\[P_l^m(\cos\theta) = (1-u^2)^{\frac{|m|}{2}}\frac{d^{|m|}}{du^{|m|}}P_l(u),\quad |m|\le l,\qquad (l+1)P_{l+1}(u) = (2l+1)\,u\,P_l(u) - lP_{l-1}(u)\]
(9.14)

תרשים של מספר פונקציות מסדרת פונקציות זו ניתן לראות באיור 70. הפונקציות \(Y_\ell^m(\varphi,\theta)\) נקראות spherical harmonics, והן למעשה מהוות בסיס דו־ממדי שלם לפריסת פונקציה כלשהי על שפתו של כדור.

9.2דוגמא 1

חרוט PEC אינסופי בעל זווית ראש \(\alpha\) נתון בפוטנציאל \(V\). החרוט נמצא מעל מישור אינסופי PEC מוארק. עלינו לפתור את הפוטנציאל \(\Phi\) בין החרוט למשטח. בעיה זו מתאימה לפתרון בקורדינטות כדוריות, מכיוון שתנאי השפה נתונים על משטחים שווי קורדינטה \(\theta\). החרוט קרוב מאוד למשטח אך לא נוגע בו (עובדה זו צריכה לרמוז לנו שאנו צפויים לקבל שדות חזקים מאוד סמוך ל”שפיץ” של החרוט). הבעיה נתונה באיור 71. תנאי השפה יהיו

\[\Phi(\theta=\pi/2) = 0,\qquad \Phi(\theta=\alpha) = V\]
(9.15)

נבחר בפתרון הטריוויאלי (היחיד שמאפשר לפוטנציאל להיות בלתי תלוי בקורדינטה \(r\) על פני החרוט)

\[\Phi = E\cdot\ln\left(\tan(\theta/2)\right) + F\]
(9.16)

ונציב תנאי שפה:

\[\begin{cases}\Phi(\theta=\pi/2) = E\cdot\ln\left(\tan(\pi/4)\right) + F = F = 0\\[1ex] \Phi(\theta=\alpha) = E\cdot\ln\left(\tan(\alpha/2)\right) = V \;\Rightarrow\; E = \dfrac{V}{\ln\left(\tan(\alpha/2)\right)}\end{cases}\]
(9.17)

נקבל

\[\Phi = V\cdot\frac{\ln\left(\tan(\theta/2)\right)}{\ln\left(\tan(\alpha/2)\right)}\]
(9.18)

נמצא את השדה החשמלי

\[\vec E = -\nabla\Phi = -\frac1r\frac{\partial\Phi}{\partial\theta}\,\hat\theta = -\frac{V}{\ln\left(\tan(\alpha/2)\right)}\cdot\frac{1}{r\sin\theta}\,\hat\theta\]
(9.19)

באיור 72 ניתן לראות את הפוטנציאל והשדה החשמלי בין החרוט למשטח.

9.3דוגמא 2

נתונה קליפה כדורית עשויה מוליך אידאלי שרדיוסה \(a\). במרכז הקליפה מונח דיפול נקודתי בעל מומנט דיפול \(\vec p = p\hat z\). הקליפה מחוברת לפוטנציאל \(V\), כמוראה באיור 73. מחוץ לכדור אין מטענים, לכן נפתור שם את משוואת לפלאס. בתוך הכדור יש פילוג מטען נתון (דיפול) ולכן נפתור את משוואת פואסון.

הפתרון מחוץ לכדור

תנאי השפה יהיו

\[\begin{cases}\Phi_1(r=a) = V\\ \Phi_1(r\to\infty) = 0\end{cases}\]
(9.20)

נבחר:

\[\Phi_1 = \frac Ar + B,\qquad \begin{cases}\Phi_1(r=a) = \dfrac Aa = V\\[1.5ex] \Phi_1(r\to\infty) = B = 0\end{cases}\]
(9.21)

ולכן נקבל:

\[\Phi_1 = V\cdot\frac ar\]
(9.22)

בתוך הכדור

\[\Phi_2 = \Phi_p + \Phi_h\]
(9.23)

הפתרון הפרטי יהיה פתרון של דיפול במרחב חופשי:

\[\Phi_p = \frac{p\cos\theta}{4\pi\epsilon_0r^2}\]
(9.24)

תנאי השפה הוא:

\[\Phi_2(r=a) = \Phi_p(r=a) + \Phi_h(r=a) = V \;\Rightarrow\; V = \Phi_h(r=a) + \frac{p\cos\theta}{4\pi\epsilon_0a^2} \;\Rightarrow\; \Phi_h(r=a) = V - \frac{p\cos\theta}{4\pi\epsilon_0a^2}\]
(9.25)

נבחר פתרון מהצורה:

\[\Phi_h = A + \underbrace{\frac Br}_{=0\text{ min/max principle}} + \Big(Cr + \underbrace{\frac{D}{r^2}}_{=0\text{ min/max principle}}\Big)\underbrace{\cos\theta}_{P_1^0(\cos\theta)} = A + Cr\cos\theta\]
(9.26)

נציב את תנאי השפה:

\[\Phi_h(r=a) = A + Ca\cos\theta = V - \frac{p\cos\theta}{4\pi\epsilon_0a^2}\]
(9.27)

הביטוי צריך להיות נכון לכל \(\theta\)

\[A = V,\qquad C = -\frac{p}{4\pi\epsilon_0a^3}\]
(9.28)

נציב כדי לקבל את הפוטנציאל בפנים

\[\Phi_2 = \Phi_h + \Phi_p = \underbrace{V - \frac{p\cos\theta\,r}{4\pi\epsilon_0a^3}}_{\text{Reaction}} + \underbrace{\frac{p\cos\theta}{4\pi\epsilon_0r^2}}_{\text{Source}} = V + \frac{p}{4\pi\epsilon_0}\left(\frac{1}{r^2} - \frac{r}{a^3}\right)\cos\theta\]
(9.29)

גם כאן ניתן לראות שניתן לחלק את הפתרון ל”פוטנציאל מעורר”, שנוצר על ידי המקור, ופוטנציאל תגובה. באיורים 74 ו־75 ניתן לראות את הפוטנציאלים והשדות.

מה צפיפות המטען על שפת הכדור?

\[\eta = \hat r\cdot\left(\epsilon_0\vec E_{out} - \epsilon_0\vec E_{inside}\right) = \left[-\epsilon_0\frac{\partial\Phi_1}{\partial r} + \epsilon_0\frac{\partial\Phi_2}{\partial r}\right]_{r=a} \;\Rightarrow\; \eta = \epsilon_0\frac Va - \frac{3p}{4\pi a^3}\cos\theta\]
(9.30)

למעשה, האיבר בצפיפות המטען שפרופורציונלי ל־\(\cos\theta\) נותן מומנט דיפולי ש”מקזז” את \(p\) מחוץ למבנה.

כיצד הפתרון שלנו היה משתנה אם הדיפול לא היה בכיוון \(\hat z\) אלא בכיוון כללי כלשהו? במקרה זה, הפתרון הפרטי היה

\[\Phi_p = \frac{\vec p\cdot\hat r}{4\pi\epsilon_0r^2} = \frac{p_x\sin\theta\cos\varphi + p_y\sin\theta\sin\varphi + \overbrace{p_z\underbrace{\cos\theta}_{P_1(\cos\theta)}}^{\text{We've already solved}}}{4\pi\epsilon_0r^2}\]
(9.31)

ולכן נוסיף לפתרון המלא תרומה של פונקציות לז׳נדר \(P_1^1\).

9.4דוגמא 3: כדור מוליך אידאלי בשדה אחיד

נתון כדור עשוי מוליך אידאלי שרדיוסו \(a\). הכדור נמצא באיזור בו שורר שדה חשמלי אחיד \(\vec E = -E_0\hat z\), כמוראה באיור 76. עלינו לפתור את הפוטנציאל והשדה בכל המרחב. תנאי השפה יהיו

\[\begin{cases}\Phi(r=a) = C = 0\\ \Phi(r\gg a) = E_0z + C_2 = E_0r\cos\theta + C_2 = E_0r\cos\theta\end{cases}\]
(9.32)

נבחר פתרון מהצורה:

\[\Phi = \underbrace{\left(Ar + \frac{B}{r^2}\right)\cos\theta}_{\text{General solution with }l=1,\,m=0}\]
(9.33)

נציב תנאי שפה

\[\begin{cases}\Phi(r=a) = \left(Aa + \dfrac{B}{a^2}\right)\cos\theta = 0\\[1.5ex] \Phi(r\gg a)\approx Ar\cos\theta = E_0r\cos\theta \;\Rightarrow\; A = E_0\end{cases}\]
(9.34)

ונקבל

\[B = -E_0a^3\]
(9.35)

הפתרון יהיה:

\[\Phi = \underbrace{E_0r\cos\theta}_{\Phi_{ext}} - \underbrace{E_0\frac{a^3}{r^2}\cos\theta}_{\Phi_{reaction}} = E_0\left(r - \frac{a^3}{r^2}\right)\cos\theta\]
(9.36)

גם כאן ניתן לחלק את הפוטנציאל במרחב לפוטנציאל המעורר (הפוטנציאל הנובע מהשדה האחיד) ופוטנציאל תגובה. פוטנציאל התגובה נראה בדיוק כמו פוטנציאל של דיפול בראשית, מכוון בכיוון \(\hat z\). השדה יהיה

\[\vec E = -E_0\hat z - E_0\frac{a^3}{r^3}\cdot\left(2\cos\theta\,\hat r + \sin\theta\,\hat\theta\right)\]
(9.37)

וניתן לראות תרשים של הפוטנציאל והשדה באיור 77. איך נראה פילוג המטען על שפת הכדור?

\[\eta = \hat r\cdot\big(\epsilon_0\vec E_{out} - \underbrace{\epsilon_0\vec E_{in}}_{=0}\big) = -3E_0\epsilon_0\cos\theta\]

וגם פילוג המטען נראה כפילוג שנותן דיפול אפקטיבי (פרופורציונלי ל־\(\cos\theta\)).

9.5*התנהגות סינגולרית בשדות: קודקוד של חרוטהעשרה והרחבה

בפרק 8 (סעיפים 8.4.1 ו־8.5) דיברנו על התנהגות סינגולרית של שדות ב”שפיץ”, וקישרנו התנהגות זו לכליא ברק. עם זאת, כליא ברק אינו ”שפיץ” גלילי, כלומר אינו קצה של גזרה גלילית אינסופית, אלא הוא למעשה קודקוד של חרוט. בסעיף זה נחזור על אותו דיון עבור מבנה כדורי.

נתון חרוט עשוי מוליך אידאלי ומוארק, שקודקודו בראשית. התחום שבו אנו פותרים את הפוטנציאל הוא החלק של כדור ברדיוס \(a\) שנמצא מעל החרוט, \(0\le\theta\le\alpha\), ועל שפת הכדור נתון הפוטנציאל \(V(r=a) = V_0(\theta)\) (איור 77א). כאשר \(\alpha\gt\pi/2\) החרוט המוליך צר, והקודקוד שלו הוא ”שפיץ” חד, כמו בכליא ברק.

נניח לשם פשטות שהפוטנציאל על שפת הכדור אינו תלוי בזווית \(\varphi\), ולכן גם הפתרון אינו תלוי בה. מאחר וציר \(z\) (\(\theta = 0\)) והראשית נמצאים בתחום הפתרון, הפתרון צריך להיות סופי שם, ולכן נבחר את הפתרון הכללי בלי הפונקציות \(Q_\nu\) ובלי האיבר \(r^{-\nu-1}\):

\[\Phi = V_\nu P_\nu(\cos\theta)\,r^\nu\]
(9.38)

כאשר הפעם \(\nu\) אינו חייב להיות שלם, מאחר ואיננו פותרים בכל התחום \(0\le\theta\le\pi\). תנאי השפה:

\[\begin{cases}1.\quad \Phi(r = a) = V_\nu P_\nu(\cos\theta)\,a^\nu = V_0(\theta)\\ 2.\quad \Phi(\theta = \alpha) = V_\nu P_\nu(\cos\alpha)\,r^\nu = 0\end{cases}\]
(9.39)

מתנאי שפה 2, הערכים המותרים של \(\nu\) הם אלו המקיימים

\[P_\nu(\cos\alpha) = 0\]
(9.40)

קיים אוסף בדיד ואינסופי של ערכים \(\nu_n\) המקיימים את תנאי שפה 2 (איור 77ב). כאשר \(\alpha = \pi/2\) (הקו השחור באיור), מתקבלים בדיוק \(\nu_n = 1, 3, 5, \dots\), מאחר ופולינומי לז׳נדר האי־זוגיים מתאפסים ב־\(\cos\alpha = 0\). חשוב במיוחד הערך הראשון \(\nu_1\): כאשר \(\alpha\gt\pi/2\) מתקיים \(\nu_1\lt1\), וכאשר \(\alpha\lt\pi/2\) מתקיים \(\nu_1\gt1\).

מכאן שהפתרון הוא טור, שאת מקדמיו נקבל מתנאי שפה 1:

\[\Phi = \sum_n V_nP_{\nu_n}(\cos\theta)\left(\frac ra\right)^{\nu_n},\qquad V_0(\theta) = \sum_n V_nP_{\nu_n}(\cos\theta)\]
(9.41)

נחשב את השדה החשמלי, באמצעות הגרדיאנט בקורדינטות כדוריות:

\[\vec E = -\nabla\Phi = -\sum_n\frac{V_n}{a^{\nu_n}}\left[\nu_nP_{\nu_n}(\cos\theta)\,\hat r - \sin\theta\,P'_{\nu_n}(\cos\theta)\,\hat\theta\right]r^{\nu_n-1}\]
(9.42)

קרוב לקודקוד, \(r\to0\), האיבר הראשון בטור הוא הדומיננטי, ולכן \(|\vec E|\propto r^{\nu_1-1}\). מכאן שהשדה סינגולרי בקודקוד אם \(\nu_1\lt1\), וזה בדיוק מה שמתרחש כאשר \(\alpha\gt\pi/2\), כלומר כאשר החרוט המוליך הוא ”שפיץ” חד.

אנרגיה

גם כאן ניתן להשוות את שני סוגי הסינגולריות בהם טיפלנו, מבחינת צפיפות האנרגיה וסך האנרגיה. צפיפות האנרגיה היא

\[u_E = \frac{\epsilon_0}{2}|\vec E|^2 = \frac{\epsilon_0}{2}\sum_{n,m}\frac{V_nV_m}{a^{\nu_n+\nu_m}}\left[\nu_n\nu_mP_{\nu_n}P_{\nu_m} + \sin^2\theta\,P'_{\nu_n}P'_{\nu_m}\right]r^{\nu_n+\nu_m-2}\]
(9.43)

ונבצע אינטגרציה על התחום, עם אלמנט הנפח \(r^2\sin\theta\,dr\,d\theta\,d\varphi\):

\[U_E = \int u_E\,dV = 2\pi\frac{\epsilon_0}{2}\sum_{n,m}\frac{V_nV_m}{a^{\nu_n+\nu_m}}\underbrace{\int_0^\alpha\left[\nu_n\nu_mP_{\nu_n}P_{\nu_m} + \sin^2\theta\,P'_{\nu_n}P'_{\nu_m}\right]\sin\theta\,d\theta}_{=0,\ \forall n\neq m}\int_0^a r^{\nu_n+\nu_m}\,dr\]
(9.44)

האינטגרל על \(\theta\) מתאפס עבור \(n\neq m\), בדומה למקרה הגלילי (פונקציות הבסיס \(P_{\nu_n}(\cos\theta)\) אורתוגונליות בתחום \([0,\alpha]\)). נסמן את האינטגרל עבור \(n = m\) ב־\(A_n = \int_0^\alpha\left[\nu_n^2P_{\nu_n}^2 + \sin^2\theta\,P'^2_{\nu_n}\right]\sin\theta\,d\theta\), ונקבל

\[U_E = 2\pi\frac{\epsilon_0}{2}\sum_n\frac{V_n^2A_n}{a^{2\nu_n}}\cdot\frac{a^{2\nu_n+1}}{2\nu_n+1} = \pi\epsilon_0\,a\sum_{n=1}^{\infty}\frac{V_n^2A_n}{2\nu_n+1}\]
(9.45)
המסקנה

האינטגרל הרדיאלי \(\int_0^ar^{2\nu_n}\,dr\) מתכנס עבור כל \(\nu_n\gt0\), כלומר עבור כל זווית \(\alpha\). לכן, כמו במקרה הגלילי, גם כאשר \(\alpha\gt\pi/2\) והשדה בקודקוד מתבדר, האנרגיה האגורה סביב הקודקוד סופית: הסינגולריות של השדה אינטגרבילית. השאלה אם האנרגיה הכוללת סופית תלויה רק בפוטנציאל \(V_0(\theta)\) על שפת הכדור, באותו אופן שראינו בסעיף 8.5.

סיכום

חרוט מעל מישור מוארק (דוגמא 1)\(\alpha\lt\pi/2\)\(\alpha\gt\pi/2\)
שדה\(|\vec E|\propto\frac{1}{r\sin\theta}\): מתבדר בקודקוד כמו \(1/r\)\(|\vec E|\propto r^{\nu_1-1}\), עם \(\nu_1\gt1\): מתאפס בקודקוד\(|\vec E|\propto r^{\nu_1-1}\), עם \(\nu_1\lt1\): מתבדר בקודקוד
צפיפות אנרגיה\(\propto1/r^2\): מתבדרת בקודקוד\(\propto r^{2(\nu_1-1)}\): מתאפסת בקודקוד\(\propto r^{2(\nu_1-1)}\): מתבדרת בקודקוד
סך אנרגיההאנרגיה בכדור ברדיוס \(R\) סביב הקודקוד פרופורציונלית ל־\(R\): סופית, ושואפת לאפס כש־\(R\to0\)סופיתסופית, למרות שהשדה מתבדר

שימו לב להבדל מהמקרה הדו־ממדי: בדוגמא 1 של פרק 8 (משוואה 8.38), שבה שני משטחים בפוטנציאלים שונים נפגשים, האנרגיה מתבדרת לוגריתמית סביב הראשית. בחרוט שמעל מישור מוארק (דוגמא 1 בפרק זה) השדה מתבדר באותו אופן, כמו \(1/r\), אבל בשלושה ממדים אלמנט הנפח \(r^2dr\) מפצה על כך, והאנרגיה סביב הקודקוד סופית.

9.6מושג הקיטוביות (Polarizability)

בדוגמא הקודמת קיבלנו תוצאה שניתן לפרשה באופן הבא: הכדור הוכנס לאיזור שבו שורר שדה חיצוני כלשהו. השדה החיצוני ”השרה” מומנט דיפול בכדור על ידי סידור מחדש של המטענים בו. מה מומנט הדיפול השקול שיוצר את שדה התגובה?

\[|\Phi_{response}| = E_0\frac{a^3}{r^2}\cos\theta,\qquad \Phi_{dip} = \frac{p\cos\theta}{4\pi\epsilon_0r^2}\]
(9.46)

נשווה מקדמים:

\[\frac{p}{4\pi\epsilon_0} = E_0a^3 \;\Rightarrow\; p = 4\pi\epsilon_0a^3E_0 = \epsilon_0\cdot3\underbrace{\frac{4\pi a^3}{3}}_{\text{Volume }V}\cdot\underbrace{(E_0)}_{\text{exciting field}}\]
(9.47)

(מומנט הדיפול מכוון בכיוון השדה המעורר, \(-\hat z\).) מאחר וקיבלנו שמומנט הדיפול \(p\) פרופורציונלי לשדה המעורר \(E_0\), ניתן מכאן להגדיר את הקיטוביות \(\alpha\) כמקדם הפרופורציה בין השניים (עד כדי הכפלה ב־\(\epsilon_0\)), כלומר

\[p = \epsilon_0\alpha E_0 \;\Rightarrow\; \alpha = 3V\]
(9.48)

הקיטוביות \(\alpha\) היא גודל שתלוי בתכונות החלקיק והסביבה שבה הוא נמצא. במקרה כאן \(\alpha\) היא סקלר, ומייצגת מצב שבו מומנט הדיפול המתעורר הוא תמיד בכיוון השדה החיצוני, ועוצמתו פרופורציונלית לשדה החיצוני דרך אותו מקדם פרופורציה. עם זאת, היא יכולה להיות גם מטריצה שמייצגת תגובה שונה לשדה בכיוונים שונים.

מה קורה אם הכדור מוכנס לאיזור שבו השדה אינו אחיד? באופן כללי זו בעיה מסובכת. עדיין לשדה הכולל בבעיה (חיצוני ועוד תרומת השדה מהכדור עצמו) יהיה המבנה

\[\vec E_{full} = \vec E_{ext} + \vec E_{dip},\qquad \vec p = \alpha\vec E_{ext} = \alpha\vec E_{local}\]
(9.49)

במשוואה האחרונה החלפנו את סימון השדה החיצוני \(E_{ext}\) ב־\(E_{local}\). בבעיה אותה פתרנו, הכדור היה מונח במרחב חופשי. עם זאת, הקיטוביות פותחת בפנינו את האפשרות לחשב את התגובה של מבנים מורכבים, בהם השדה שיפעל על כל חלקיק לא יהיה רק השדה החיצוני, אלא יושפע גם ממבנים שכנים. השדה הלוקאלי \(E_{local}\) למעשה מגדיר את השדה שמעורר את החלקיק. זהו השדה הכולל בנקודה שבה מונח החלקיק, למעט השדה שנוצר ישירות על ידי החלקיק עצמו (אבל כולל התרומה של כל הגופים השכנים).

9.7שדות אלקטרוסטטיים בתווך בעל מוליכות סופית

בואקום, קיבלנו את משוואת לפלאס על ידי השיקולים הבאים

\[\nabla\times\vec E = 0 \;\Rightarrow\; \vec E = -\nabla\Phi\]
(9.50)
\[\nabla\cdot\epsilon_0\vec E = \rho = 0\]
(9.51)

ולאחר הצבה של 9.50 ב־9.51 נקבל \(\nabla^2\Phi = 0\). כאשר יש לנו חומר מוליך, המקיים את חוק אוהם \(\vec J = \sigma\vec E\), שיכולים לזרום בו זרמים, לא ברור מיידית שאנחנו יכולים להניח את הנחה מספר 2, שאין מטענים חופשיים במוליך, מאחר ויכולים לזרום בו זרמים. במקום זאת, אנו יכולים להשתמש בעובדה שמאחר ומדובר בבעיה סטטית מתקיים

\[\nabla\cdot\vec J = -\frac{\partial\rho}{\partial t} = 0\]
(9.52)

וכעת, אם נציב את חוק אוהם נקבל

\[\nabla\cdot\vec J = \nabla\cdot\left(\sigma\vec E\right) = \sigma\nabla\cdot\vec E = 0 \;\Rightarrow\; \nabla\cdot\vec E = 0\]
(9.53)

ומכאן ניתן, בצירוף הנחה 1, לקבל שוב את משוואת לפלאס. חשוב לשים לב שבמעבר האחרון הסתמכנו על כך שהמוליכות אחידה. במקרה והמוליכות אינה אחידה מתקיים

\[\begin{gathered}\nabla\cdot\vec J = 0 \;\Rightarrow\; \nabla\cdot\left(\sigma(\vec r)\vec E\right) = \sigma(\nabla\cdot\vec E) + (\nabla\sigma(\vec r))\cdot\vec E = 0\\ \nabla\cdot\left(\sigma(\vec r)\vec E\right) = 0,\quad \nabla\cdot(\epsilon_0\vec E) = \rho \;\Rightarrow\; \underbrace{\frac{\rho}{\epsilon_0} = \nabla\cdot\vec E}_{\text{Gauss}} = -\frac1\sigma(\nabla\sigma)\cdot\vec E\end{gathered}\]
(9.54)

כלומר, במצב סטטי, בתחום שמוליכותו לא אחידה חייב להצבר פילוג מטען חופשי בכל מקום בו המוליכות משתנה. בין אם מדובר בשינוי רציף, ואז נחשב את צפיפות המטען על ידי הפיתוח שניתן כאן, ובין אם מדובר בשינוי דיסקרטי, כלומר קפיצה במוליכות, כמו שנראה בדוגמא הבאה. במקרה זה חישוב פילוג המטען באיזור אי הרציפות יתבצע באמצעות שימוש בתנאי השפה.

9.7.1דוגמא

נתון מבנה גלילי שרדיוסו \(a\). חלקו העליון בגובה \(h_1\) ובמוליכות \(\sigma_1\). חלקו התחתון בגובה \(h_2\) ובמוליכות \(\sigma_2\), כמוראה באיור 78. את שפתו העליונה של המבנה מצפים בחומר מוליך ומחברים לפוטנציאל \(V\). את שפתו התחתונה גם כן מצפים בחומר מוליך ומאריקים. יש לחשב את השדות והזרמים במבנה. המשוואה שעלינו לפתור בתוך האזורים בהם המוליכות לא משתנה היא משוואת לפלאס. תנאי שפה לחוק שימור המטען

\[\hat n\cdot(\vec J_a - \vec J_b) + \nabla_S\cdot\vec K = -\frac{\partial\eta}{\partial t} \;\Rightarrow\; \begin{cases}\text{at } r=a:\quad \hat r\cdot\vec J = 0\\ \text{at } z=h_2:\quad \hat z\cdot(\vec J_1 - \vec J_2) = 0\end{cases}\]
(9.55)

כאשר הנחנו כי על השפה בין חומר בעל מוליכות סופית למבודד לא זורם זרם משטחי (ולכן \(\vec K = 0\)), ואנו בבעיה סטטית (לכן \(-\partial\eta/\partial t = 0\)). תנאי שפה לפוטנציאל

\[\begin{cases}\Phi_{z=0} = 0\\ \Phi_{z=h_1+h_2} = V\\ \Phi_1(z=h_2) = \Phi_2(z=h_2)\end{cases}\]
(9.56)

נבחר בפתרון הטריוויאלי

\[\begin{cases}\Phi_1 = A_1z + B_1\\ \Phi_2 = A_2z + B_2\end{cases}\]
(9.57)

ב־\(z = 0\)

\[\Phi_2(z=0) = B_2 = 0 \;\Rightarrow\; \Phi_2 = A_2z\]
(9.58)

לאחר הצבת תנאי שפה נקבל

\[\begin{cases}\Phi_1 = \dfrac{V}{h_1 + h_2\frac{\sigma_1}{\sigma_2}}\,z + \left(\dfrac{\sigma_1}{\sigma_2} - 1\right)h_2\,\dfrac{V}{h_1 + h_2\frac{\sigma_1}{\sigma_2}}\\[3ex] \Phi_2 = \dfrac{\sigma_1}{\sigma_2}\,\dfrac{V}{h_1 + h_2\frac{\sigma_1}{\sigma_2}}\,z\end{cases}\]
(9.59)

תרשים של הפוטנציאל עבור מקרים שונים ניתן לראות באיור 79, ובנוסף, ניתן ”לשחק” עם הפרמטרים בקישור. מה סך הזרם החולף בהתקן?

\[\begin{gathered}\vec E_2 = -\nabla\Phi_2 = -\frac{\sigma_1}{\sigma_2}\frac{V}{h_1 + h_2\frac{\sigma_1}{\sigma_2}}\,\hat z \;\Rightarrow\; \vec J_2 = \sigma_2\vec E_2 \;\Rightarrow\; I = \sigma_1\cdot\pi a^2\frac{V}{h_1 + h_2\frac{\sigma_1}{\sigma_2}} = \frac{V}{R_{eq}}\\ \Rightarrow\; R_{eq} = \frac{h_1 + h_2\frac{\sigma_1}{\sigma_2}}{\sigma_1\pi a^2} = \underbrace{\frac{h_1}{\pi a^2}\cdot\frac{1}{\sigma_1}}_{\text{Resistance of the top part}} + \underbrace{\frac{h_2}{\pi a^2}\cdot\frac{1}{\sigma_2}}_{\text{Resistance of the bottom part}}\end{gathered}\]
(9.60)

כלומר קיבלנו שההתנגדות השקולה של ההתקן היא חיבור בטור של ההתנגדויות של החלקים הנפרדים.

9.7.2*הרחבה: מטענים על השפה החיצונית של הגלילהעשרה והרחבה

בפתרון של סעיף 9.7.1 התייחסנו רק לשדה בתוך הגליל, וקיבלנו שבכל אחד משני החלקים השדה אחיד ומכוון לאורך הציר. מטען חופשי מצאנו רק בממשק בין שני החלקים, שבו המוליכות משתנה. אבל בבעיה אמיתית יש גם שדה מחוץ לגליל, ולכן נשאלת השאלה מה קורה על השפה החיצונית שלו, \(r = a\).

על השפה החיצונית זורם הזרם רק בתוך הגליל, ולכן תנאי השפה לשימור המטען במצב סטטי הוא

\[\hat r\cdot\vec J\big|_{r=a^-} = 0 \;\Longrightarrow\; \hat r\cdot\vec E\big|_{r=a^-} = 0\]
(9.61)

כלומר, בצד הפנימי של השפה השדה מקביל לשפה. הפתרון שמצאנו מקיים תנאי זה, כי השדה בתוך הגליל מכוון לאורך \(\hat z\). לעומת זאת, הפוטנציאל רציף על השפה, ולכן מחוץ לגליל הפוטנציאל צריך להשתנות לאורך הדופן בדיוק כמו בפנים: לינארית בכל חלק, עם ”שבירה” בגובה הממשק. השדה מחוץ לגליל, שנקבע גם על ידי שאר הגופים במרחב (המקור, החוטים, ההארקה), יכול לקבל במקרה כזה רכיב ניצב לדופן. מתנאי השפה של חוק גאוס נקבל שעל הדופן נצברת צפיפות מטען משטחית

\[\eta(z) = \hat r\cdot\left(\epsilon_0\vec E_{out} - \epsilon_0\vec E_{in}\right)\Big|_{r=a} = \epsilon_0\,E_{out,r}(a,z)\]
(9.62)

כלומר, במצב אמיתי מצטברים מטענים על השפה החיצונית של שני חלקי הגליל, כפי שלמעשה מצטברים בכל מקום שבו המוליכות אינה אחידה: בממשק בין שני החומרים, וגם בשפה שבין המוליך לאוויר שסביבו.

בסימולציה ניתן לראות כמה דברים:

  • השדה בתוך הגליל (חתך במרכז האיור) אחיד ומכוון לאורך הציר, בדיוק כמו בפתרון שקיבלנו, והוא חזק יותר בחלק העליון, שבו המוליכות נמוכה יותר.
  • על הדופן החיצונית נצבר מטען חיובי סמוך למכסה העליון, שנמצא בפוטנציאל \(V\), ומטען שלילי סמוך למכסה המוארק. מחוץ לגליל השדה כבר אינו מקביל לדופן, ויש לו רכיב ניצב, בהתאם למשוואה 9.62.
  • על הממשק בין שני החלקים צפיפות המטען שלילית. זו בדיוק התוצאה שקיבלנו בסעיף 9.7.1: \(\eta = \epsilon_0(E_{2,z} - E_{1,z})\), וכאשר \(\sigma_1\lt\sigma_2\) השדה בחלק העליון חזק יותר, ולכן \(\eta\lt0\).
מדוע הפתרון הפנימי עדיין נכון?

בתוך הגליל הפוטנציאל מקיים את משוואת לפלאס, עם הפוטנציאלים הנתונים על שני המכסים ועם התנאי \(\hat r\cdot\vec E = 0\) על הדופן מבפנים (משוואה 9.61). תנאים אלו קובעים את הפתרון בתוך הגליל באופן יחיד, בלי תלות במה שקורה בחוץ. לכן השדה בפנים אכן אחיד בכל חלק, כמו שקיבלנו. המטענים על הדופן החיצונית הם ”המחיר” שהמערכת משלמת כדי שזה יקרה: הם נצברים בדיוק בפילוג שנדרש כדי שהשדה בתוך המוליך יישאר מקביל לדופן, כך שהזרם לא ”יברח” החוצה. זהו אותו מנגנון שבזכותו זרם זורם לאורך חוט מתכתי מתעקל: מטענים משטחיים זעירים על החוט ”מכוונים” את השדה בתוכו לאורך החוט.
